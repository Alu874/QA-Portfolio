# QA Portfolio – Aldana Gabriela Perez

De bibliotecaria a QA Tester. Este repositorio documenta mi transición de carrera hacia Quality Assurance, con proyectos que combinan formación formal, estudio independiente y práctica aplicada.

## 🎯 Sobre mí

Vengo de bibliotecología y docencia, campos donde el pensamiento sistemático, la documentación rigurosa y la atención al detalle son el pan de cada día. Hoy aplico esas mismas habilidades al testing de software.

**Formación:**
- 🎓 EducaciónIT – Análisis y Diseño de Casos de Prueba
- 🎓 Udemy – Introducción al Testing de Software
- 📚 Estudio independiente de SQL/MySQL (XAMPP + phpMyAdmin)
- 📚 Estudio independiente de testing de APIs (Postman)

## 📂 Proyectos

### [01 – Suite de Casos de Prueba: Login](./01-login-test-suite)
Diseño completo de casos de prueba (CP-01 a CP-06) para un módulo de login, incluyendo casos positivos, negativos y de borde. Documentado en Qase.

### [02 – Reportes de Bugs](./02-bug-reports)
Reportes de bugs siguiendo un template profesional de 7 campos, incluyendo un defecto de seguridad y un defecto cosmético.

### [03 – Testing ACADEU (Proyecto Ficticio)](./03-acadeu-testing)
Escenario de testing inspirado en una plataforma de comunicación escuela-familia. Incluye smoke testing, testing funcional y testing de regresión.

### 04 – Testing de APIs y SQL
*Próximamente* – Casos de prueba de API (Postman) y consultas SQL aplicadas a testing de bases de datos.
